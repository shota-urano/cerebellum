# デザイン原則（正本）

## トーン

**FUI/HUD 計器盤**。深紺の闇に、情報だけがシアンに発光する。
毎朝・毎晩の数秒の消し込み操作が主なので、装飾は「発光する境界線・リング・セグメントバー」に限定し、
イラスト・グラデーション面・大きな装飾を置かない。**消し込むほど画面の発光が増える**（done の
グローが達成感の演出であり唯一のリッチ表現）。

## 情報密度・デバイス

- モバイルファースト（iOS Safari・390px 基準）。PC は同一レイアウトの中央寄せ（max-w-2xl）
- 1画面1リスト。1日のタスクは十数件想定——スクロール最小で全体が見える密度
- 操作はタップのみ（hover 依存の情報を作らない。hover は装飾強化どまり）

## テーマ

**常時ダーク**。OS 設定に追従しない。light テーマのトークン・スタイルを作らない
（要件定義 §5・specs 07 §4 も 2026-07-26 に同旨へ改訂済み）。

## アクセシビリティ

- text（#D7E9FF）on bg（#050B1A）はコントラスト比 約15:1、muted も 4.5:1 以上を維持する
- 状態は色だけで伝えない（done は打ち消し線＋リング、エラーは文言、readonly はバッジ併用）
- タップターゲット 44px 以上（確定値）
- アニメーションはグローとチェック遷移の 150–200ms のみ。`prefers-reduced-motion` で無効化

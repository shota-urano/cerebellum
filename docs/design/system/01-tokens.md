# デザイントークン（正本）

確定: 2026-07-26（ユーザー承認済み）。**常時ダーク**（light テーマは持たない）。
参考イメージ: FUI/HUD ホログラムインターフェース（深紺＋電光シアン）。

## 色（意味ベース。系統Bはこの名前を CSS 変数にする）

| トークン | 値 | 用途 |
|---|---|---|
| `--color-bg` | `#050B1A` | 画面背景（最深部の紺黒） |
| `--color-surface` | `#0D1B36` | カード・リスト行・バナーの面 |
| `--color-border` | `#16305E` | 1px の微発光境界線・区切り線 |
| `--color-text` | `#D7E9FF` | 本文（氷白。純白は使わない） |
| `--color-text-muted` | `#5F7AA6` | 補助情報（時刻・ツール名・完了済みタスク） |
| `--color-accent` | `#38E5FF` | 電光シアン。**完了・進捗・フォーカスに限定**（多用しない） |
| `--color-accent-glow` | `rgba(56,229,255,0.45)` | グロー（`box-shadow: 0 0 8px`） |
| `--color-danger` | `#FF5C7A` | エラーバナー・失敗状態（ネオン赤） |

## タイポグラフィ

- 本文: **Noto Sans JP**（`next/font/google` でセルフホスト。フォールバック `system-ui`）
- **数字・時刻・進捗・日付: JetBrains Mono**（同セルフホスト。フォールバック `ui-monospace`）＋ `font-variant-numeric: tabular-nums`（計器の桁揃え）
  ※ 2026-07-26 プロトタイプ採用に伴いシステムフォントから変更（ユーザー承認済み）
- マイクロラベル（バッジ・見出しラベル）: 大文字（英字の場合）＋ `letter-spacing: 0.08em`・13px
- サイズスケール: 13 / 14 / 16(base) / 18 / 22 px

## 余白・寸法

- スペーシング: 4px スケール（4 / 8 / 12 / 16 / 24 / 32）
- タップターゲット: 最小 44px（行全体をターゲットにする）
- コンテンツ幅: `max-width: 440px` 中央寄せ（2026-07-26 プロトタイプ採用で max-w-2xl から変更）

## 角丸・効果

- カード・バナー: 6px ／ 小部品（バッジ・ボタン）: 4px（HUD は直線基調。大きい角丸を使わない）
- グロー: 完了チェック・進捗バーの到達部にのみ `0 0 8px var(--color-accent-glow)`
- 影は使わない（深さは border と面色の差で出す）

# cerebellum デザインブリーフ（Claude design 用・この1枚を新規セッションに丸ごと貼る）

## やりたいこと

自分専用の「日次ルーティン消し込みダッシュボード」のUIプロトタイプ。毎朝・毎晩スマホ（iPhone Safari）で開き、今日のタスクをタップで消し込む。1日十数件・操作は数秒。PC でも同じレイアウトを中央寄せで使う。

トーン: **サイバーな FUI/HUD 計器盤**。深紺の闇に情報だけがシアンに発光する。装飾は発光する境界線・チェックリング・セグメントバーに限定し、消し込むほど画面の発光が増えるのが唯一のリッチ表現。静かで精密、計器のような高級感。**常時ダーク**（light テーマ不要）。

## 要約デザインシステム

- 背景 `#050B1A` ／ 面 `#0D1B36` ／ 境界線 `#16305E` ／ 本文 `#D7E9FF` ／ 補助 `#5F7AA6` ／ アクセント（電光シアン・完了/進捗のみ）`#38E5FF` ／ エラー `#FF5C7A`
- 数字・時刻・進捗・日付は等幅（tabular-nums）で桁を揃える。角丸は小さく（6px/4px）・影なし
- この雰囲気に合う範囲で、レイアウト・装飾・細部の表現は自由に提案してよい

## 画面一覧（2画面・実文言をそのまま使う）

### 1. 今日（メイン画面）

- [ ] ヘッダ: 日付「2026-07-26（日）」＋進捗「4 / 13」＋13区画セグメントバー（4区画発光）
- [ ] タスクリスト（1列・行高44px以上・行全体タップでチェックON/OFF）。各行: チェックリング・内容・時刻/ツール名（等幅・補助色。ツールが空や「-」は非表示）
- [ ] 実データ（完了4件＋未完了9件）:
  - 完了: 「7:30 [slack] つながり発見」「7:30 [slack] ハーネス取り込み判定🔧の採用提案に✅ / →適用したくなったら /night-harness --apply」「8:00 [slack | obsidian] 40_Projects/noteの原稿の確認」「8:00 [orca] 40_Projectsにて新たな学習」
  - 未完了: 「8:30 [obsidian] 00_Inboxにて新たな知識」「11:00 ゴルフスイング」「12:10 [slack] リポスト確認」「18:30 ランニング」「22:00 [obsidian] 40_Projects/blindspotを確認」「英語学習（1時間）」「読書（15分）」「夜間タスクの作成→夜間に回す（1時間）」「夜間タスクの確認」
- [ ] 状態: タップで完了⇄未完了が即時トグル（完了=リング発光＋打ち消し線）／全完了時の完了表示／空状態「今日のタスクはありません」／エラーバナー「Vault が読み取れません。同期完了後に自動で再試行します」（エラー色の左ボーダー）

### 2. 履歴

- [ ] 日付ナビ: 「◀ 前日」「翌日 ▶」＋中央に「2026-07-25（土）」（未来へは進めない）
- [ ] 「読み取り専用」バッジ＋その日のタスクリスト（トグル不可の静的表示。データは今日画面と同形式でよい）
- [ ] スナップショットが無い日は「記録なし」表示
- [ ] 直近7日サマリ: 日付昇順に 日付・done/total・ミニセグメントバー。「07-20 11/13」「07-21 9/11」「07-22 記録なし」「07-23 10/11」「07-24 11/11」「07-25 8/13」「07-26 4/13」

## 出力形式

- 複数画面を含む**単一プロトタイプ（1アプリ）**でよい。画面間の遷移（今日⇄履歴）を付ける
- **README に「画面 → コンポーネント/ファイルの対応表」を必ず含める**（画面単位で採用判定するため）
- 依存は最小に。重い表現が必要ならプレースホルダ可

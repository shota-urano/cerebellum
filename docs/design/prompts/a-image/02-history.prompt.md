# A用プロンプト: 02 履歴

**対象**: 「履歴」画面（日付ナビ・読み取り専用・7日サマリ） ｜ spec: [`../../../specs/09-web-history.md`](../../../specs/09-web-history.md)
**生成**: gpt-image-2 / 縦長（1024x1536）。**基準画面（01 今日）を先に生成し、トーン・配色・密度をそれに揃える。**

## スタイルアンカー（共通ブロック・全A用ファイルで同一）

- トーン: FUI/HUD計器盤。深紺の闇に情報だけがシアンに発光。装飾は発光する境界線・リング・セグメントバーのみ
- 配色: 背景 #050B1A ／ 面 #0D1B36 ／ 境界線 #16305E（1px微発光）／ 本文 #D7E9FF（氷白）／ 補助 #5F7AA6 ／ アクセント #38E5FF（電光シアン。完了・進捗のみ、シアングロー付き）／ エラー #FF5C7A
- タイポ: 本文はモダンなサンセリフ、数字・時刻・進捗は等幅フォントで桁が揃う。マイクロラベルは字間広め
- 形状: 角丸はカード6px・小部品4pxの直線基調。影なし、深さは面色の差で表現
- デバイス: iPhone縦画面のモバイルUI（390px幅基準）、ステータスバー等のOS要素は不要

## 画面固有

- レイアウト: 上から ①DateNav（前日/翌日ボタン＋日付）②「読み取り専用」バッジ ③その日のタスクリスト（トグル無効の見た目）④7日サマリカード
- DateNav: 「◀ 前日」「翌日 ▶」のアウトラインボタンと中央に等幅の「2026-07-25（土）」
- バッジ: 「読み取り専用」のアウトラインバッジ（補助色・字間広め）
- タスクリスト: 完了行はシアン発光リング＋打ち消し線、未完了行は暗いリング。チェック操作できない静的な印象（行を薄めに）
- サマリ（SummaryCard）: 「直近7日」ラベル。日付昇順の行に 等幅の日付・done/total・ミニセグメントバー。1日だけ「記録なし」を補助色で含める
- 含める状態: 過去日 readonly＋サマリを1枚に描く

## プロンプト本体

```prompt
モバイルアプリのUIデザインモックアップ、iPhone縦画面（アスペクト比2:3の縦長キャンバスに端末フレームなしでUIのみ全面表示）。
サイバーなFUI/HUD計器盤スタイルのタスクダッシュボード「履歴」画面。基準となる「今日」画面と同じ世界観: 深紺の闇 #050B1A、カード面 #0D1B36、境界線 #16305E、氷白テキスト #D7E9FF、補助 #5F7AA6、電光シアン #38E5FF（グロー付き）。影なし・直線基調・角丸小さめ。

レイアウト（上から）:
1. 日付ナビ: 「◀ 前日」「翌日 ▶」のアウトラインボタン、中央に等幅フォントの「2026-07-25（土）」
2. 「読み取り専用」の小さなアウトラインバッジ（補助色・字間広め）
3. その日のタスクリスト（読み取り専用の静的な表示。行の面 #0D1B36）:
完了（シアン発光リング＋打ち消し線）:「7:30 [slack] つながり発見」「8:00 [slack | obsidian] 40_Projects/noteの原稿の確認」「8:30 [obsidian] 00_Inboxにて新たな知識」「12:10 [slack] リポスト確認」「英語学習（1時間）」
未完了（暗いアウトラインリング）:「11:00 ゴルフスイング」「18:30 ランニング」「読書（15分）」
4. 「直近7日」サマリカード: 日付昇順の行に等幅の日付・達成数・ミニセグメントバー:
「07-20  11/13」「07-21  9/11」「07-22  記録なし」「07-23  10/11」「07-24  11/11」「07-25  8/13」「07-26  4/13」
（記録なしの行は補助色テキストのみ、バーなし）

日本語テキストは崩さず正確に描画。写真要素・人物・イラストは入れない。UIのみ。フラットで精密、計器盤のような静かな高級感。
```
